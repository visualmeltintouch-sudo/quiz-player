# Quiz Player

Programma Windows (portable) per i totem Quiz. Uguale per tutti i clienti: i contenuti arrivano dal pacchetto offline scaricato dal Platform Admin.

Download: vedi la sezione **Releases** a destra (ultima versione: `Quiz.Player.exe`).

Uso: copia `Quiz Player.exe` e la cartella del pacchetto nella stessa cartella sul PC del totem e avvia il programma.
